# ms_categoria

Microservicio REST para la gestión de categorías de libros (puerto 8082).

## Inicio rápido

```bash
cp .env.example .env
docker compose up --build
```

API: http://localhost:8082/api/category · Swagger: http://localhost:8082/swagger-ui.html

La documentación completa (endpoints, variables de entorno, pruebas, Docker, pipeline y GitFlow) está en el [README principal](../README.md).
